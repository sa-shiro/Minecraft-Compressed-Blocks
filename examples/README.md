# Examples

This directory contains example resource-pack and datapack implementations for **CB: Compressed Blocks**.

- **`example_resourcepack/`** --- Example blockstates, models, and language assets for custom compression entries.
- **`example_datapack/`** --- Example recipes, loot tables, tags, and optional advancements for custom entries.

These examples are intended as references and starting points for modpack developers. Adapt the resources to your own
entries and Minecraft version.

For setup instructions, configuration details, and explanations of the required resources, see
the [CB Wiki](https://github.com/sa-shiro/Minecraft-Compressed-Blocks/wiki).
